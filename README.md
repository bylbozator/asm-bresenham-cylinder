# asm-bresenham-cylinder / Примитивы Брезенхема (TASM)

**Построение «цилиндра» в графическом режиме VESA 800×600×256: линии и окружности по алгоритму Брезенхема.**

[![x86](https://img.shields.io/badge/x86-16bit-00599C?logo=intel&logoColor=white)](https://en.wikipedia.org/wiki/X86_assembly_language)
[![VESA](https://img.shields.io/badge/VESA-800%20600%20x%20256-FF6C37?logo=amd&logoColor=white)](https://www.vesa.org/)

Учебная лабораторная работа по графике низкого уровня: растеризация отрезков
и окружностей без использования библиотек, только регистры и память видеобуфера.

</div>

## Что на экране

Программа рисует «цилиндр» (вид в проекции на плоскость):

- 4 вертикальных отрезка (границы и рёбра);
- большая и малая окружности как основания и сечения цилиндра (по две на разных высотах).

## Реализованные алгоритмы

| Процедура     | Что делает |
|---------------|------------|
| `drawline`    | Алгоритм **Брезенхема** для отрезка: аккумулятор ошибки `er`, шаги по `signX`/`signY` |
| `circle`      | Алгоритм **Брезенхема** для окружности: параметр `circD`, 8 симметричных точек |
| `plot`        | Запись пикселя в видеопамять `0xA000:0000` с банковским переключением |
| `setgraf`/`setbank` | Переход в VESA-режим `4F02h/103h` (800×600×256) и смена банка `4F05h` |
| `invoke`      | Макрос передачи параметров через стек |

## Как собирать и запускать

```bash
tasm fff.asm
tlink fff.obj
fff.exe        # требуется VESA-совместимый режим (DOSBox / V86)
```

Макрос `invoke` упаковывает параметры (координаты центра, радиус, цвет) в стек —
процедуры читают их через `[bp+offset]`.

## Детали

- Прямой доступ к видеопамяти с поддержкой банков (`0x4F05`) для высоких разрешений.
- Процедура `plot` отбрасывает координаты за пределами экрана (`800×600`).
- Формулы Брезенхема реализованы целочисленно — без плавающей точки.
